- **지어낸 경험담 금지**: 사용자 프롬프트에 "경험을 풀어쓴다"가 있어도 내가 직접 가 본 것처럼 쓰지 않는다. 실제 경험은 사용자가 알려 줄 때만 쓴다. 모르면 "확인 못 했다"고 쓴다.
- **확인된 정보만 게시**: 페이지에 없는 항목(줄거리, 출연진, 오픈 시각 등)은 "아직 확인하지 못한 정보"로 따로 적고, 일정 변동 가능 문구와 확인 기준 날짜를 넣는다.
- **NOL 시각 주의**: NOL 오픈 예정 목록은 날짜·시간이 오픈 시각인지 공연 일시인지 불분명한 항목이 있다. 글에 쓰기 전에 상세 페이지로 교차 확인한다.
- **캘린더는 각 분류 상단에**: 종합 글 하나가 아니라 카테고리별로 나눠 올린다.
- **네이버 소개글**: 4바이트 이모지는 삭제됨. ★ ♬ ✈ 같은 BMP 기호만 사용.
- **이미지**: 배너를 늘릴 때 그라데이션 채우기는 싫어함. 필요하면 이미지 생성 도구용 프롬프트를 준다(나는 이미지 생성 도구가 없음).
- **네이버 블로그는 내 브라우저 도구가 접근할 수 없음**(blog.naver.com, admin.blog.naver.com 모두 차단, 사용자가 허락해도 불가). 확인이 필요하면 사용자에게 스크린샷이나 텍스트 복사를 요청한다.

**Why:** 사용자가 정확한 정보와 진정성 있는 글을 원하고, 나는 네이버에 직접 접근하지 못한다.
**How to apply:** 글을 만들기 전에 이 규칙을 점검하고 막히면 사용자에게 붙여 달라고 요청한다. 관련: [[project-naver-blog-ticket-info]]
