2026-11-06 사용자가 맛집 블로거(실제 방문 사진 블로그)에게 따뜻한 말투로 서로이웃 신청·댓글을 무인 자동으로 하길 원했으나 보류했다.

**Why:** Chrome 확장이 naver.com 을 "안전 제한"으로 막는다(사용자가 허용해 달라 했으나 우회 불가). 무인 자동은 스팸 패턴이라 블로그 제한 위험이 있어 권하지 않았다. 사용자는 직접 붙여넣는 방식도 싫다고 함.
**How to apply:** 다시 요청하면 위 차단 여부를 먼저 확인하고, 안전한 범위(문구 초안 생성, 사용자가 지켜보는 소량 진행)를 제안한다. 무인 대량 자동은 하지 않는다. 관련: [[project-naver-blog-ticket-info]]
